# 09_Executive_Summaries_and_PDFs

## Purpose

Shareable documents, executive summaries, teacher guides, programmer guides, and publication drafts.

## What belongs here

- One-page summaries.
- Diagrams and architecture notes.
- Source documents and working drafts directly related to this area.
- Links or notes pointing to code, hardware, data, or publication materials.

## What does not belong here

- Unsorted files without explanation.
- Large generated files with no source note.
- Project files that belong more clearly in another numbered folder.

## Key subfolders

- `UMA_Project_Inventory/`
- `Nugget_Executive_Summaries/`
- `Teacher_Guides/`
- `Programmer_Guides/`
- `Publication_Drafts/`
