# UMA Master Architecture — One-Pager

**Tagline:** Measured World · Measured Machine · Measured Self

## One-sentence purpose

UMA organizes a lifetime of teaching architecture into a coherent, shareable system where simple measurement leads upward into science, engineering, robotics, computation, and human motion support.

## Core thesis

The work is not a collection of gadgets. It is a learning architecture built around a single human act: making the invisible measurable.

## Three environs

| Environ | Pillar | Primary question | Examples |
|---|---|---|---|
| Kitech / Kitchen Lab | Measured World | What can I measure in the physical world around me? | mass, volume, temperature, energy, cooling, boiling, calorimetry |
| Robot EDU | Measured Machine | How does measurement become motion, control, and feedback? | ToF, heading, navigation, robot arena, ECHONAV |
| WalkWise / SQM+ | Measured Self | How can motion be observed, compared, summarized, and encouraged? | cadence, rhythm, consistency, symmetry, stability |

## Technology ladder

```text
555 → 7400 → PIC / AVR → ARM → ESP32
```

The ladder begins with visible time and one-bit memory, then moves toward programmable controllers, browser dashboards, BLE/Wi-Fi, and shareable instruments.

## Teaching rule

```text
First make it measurable.
Then make it automatic.
Then make it wireless.
```

## Operating verbs

```text
Observe → Measure → Encode → Transmit → Model → Interpret → Improve
```

## Flagship set

- Singing Ruler: motion, damping, ODEs, FFT, and mathematical soul.
- Smart eScale: mass, calibration, uncertainty, KitchenLab instrumentation.
- Tapeless Ruler: distance, ToF/ultrasonic measurement, spatial sense.
- SQM+ / WalkWise: supportive motion-quality summary and feedback.
- Robot EDU / ECHONAV: sensing, navigation, confidence, and controlled motion.
- Nugget / REDBoard Revival: low-cost embedded systems and machine literacy.
- 555 + 7400 One-Bit Lab: time, latch memory, Bernoulli/binomial statistics.

## Why it matters

This architecture gives learners agency. They do not merely consume black-box outputs. They estimate, build, measure, calibrate, debug, interpret, and explain.
