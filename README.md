# UMA Archive 2026

**Measured World · Measured Machine · Measured Self**

A lifetime of teaching architecture is being organized into a shareable system where simple measurement leads upward into science, engineering, robotics, computation, and human motion support.

## What this repository is

This repository is an archival and development map for educational instruments, dashboards, firmware, comics, guides, data, and publication drafts. It is not merely a code repository. It is a structured memory palace for an integrated STEM/computation learning architecture.

## The three environs

| Environ | Pillar | Plain meaning |
|---|---|---|
| **Kitech / Kitchen Lab** | Measured World | Home-based measurement, conservation, energy, temperature, mass, volume, and everyday science. |
| **Robot EDU** | Measured Machine | Robots, sensors, navigation, feedback, control, and spatial reasoning. |
| **WalkWise / SQM+** | Measured Self | Supportive human-motion measurement: observe, compare, summarize, and encourage. |

## Technology ladder

```text
555 → 7400 → PIC / AVR → ARM → ESP32
```

This ladder connects visible timing, one-bit memory, small microcontrollers, classroom boards, ARM learning platforms, and wireless/dashboard-capable instruments.

## Teaching rule

```text
First make it measurable.
Then make it automatic.
Then make it wireless.
```

## Current status

This is an archival organizing repository. Many items are drafts, prototypes, working notes, or publication candidates. Status should be tracked in `PROJECT_STATUS.md`.

## Safety and scope

WalkWise / SQM+ language must remain educational and supportive. It does not diagnose, prescribe, or make medical decisions.

## How to use this archive

1. Start with `ARCHIVE_INDEX.md`.
2. Review `PROJECT_STATUS.md`.
3. Use templates from `templates/` when adding a project.
4. Keep one-page summaries close to each project.
5. Name it. Version it. Summarize it. Put it where it can be found.
