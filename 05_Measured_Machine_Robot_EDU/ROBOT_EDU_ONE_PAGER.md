# Robot EDU — One-Pager

**Pillar:** Measured Machine

## One-sentence purpose

Robot EDU is the learning environ where measurement becomes motion, control, feedback, spatial reasoning, and responsible machine behavior.

## Who it serves

- Students learning that robots are understandable systems, not magic boxes.
- Teachers who want measurement-rich robotics beyond line following and obstacle avoidance.
- Makers who want low-cost platforms with serious conceptual depth.
- Collaborators interested in sensors, navigation, protocols, and dashboards.

## Where it happens

Robot EDU can live on a classroom table, maker bench, taped floor arena, hallway course, box arena, or outdoor test path. The key requirement is not a fancy lab. The key requirement is a place where motion can be observed and measured.

## What it measures

| Quantity | Sensor / source | Learning doorway |
|---|---|---|
| Distance | ToF / ultrasonic / IR | space, mapping, obstacle geometry |
| Heading | magnetometer / compass | orientation, validation, navigation |
| Speed | encoder / timing / distance | kinematics, control, error |
| State | firmware variables / dashboard | logic, sequencing, finite-state thinking |
| Confidence | sensor agreement / repeatability | uncertainty, trust, decision quality |

## Learning loop

```text
Sense → Decide → Move → Correct
```

This loop makes computation visible. Students see that a line of code changes motion, and motion tests whether the code really expressed the idea.

## Why it matters

Robot EDU links the Measured World to the Measured Self. Robot paths, pendulums, rulers, and gait are all forms of constrained motion. Robots give students a safe, visible way to study measurement, decision, correction, and agency.
