# Contributing

This repository is an archive and development map. Contributions should preserve clarity.

## Guidelines

- Preserve the folder structure.
- Add a one-page summary for each new project.
- Use the templates in `templates/`.
- Do not add large generated files without noting their source.
- Keep medical/human-motion language supportive and non-diagnostic.
- Prefer clear filenames with dates or version numbers.
- Commit with meaningful messages.

## Commit message examples

```text
Add one-page summary for Smart eScale
Document PIC Black Box SNAP setup
Add draft storyboard for ECHONAV comic
Update project status table
```
